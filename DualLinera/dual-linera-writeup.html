Dual-Linera

I recovered the hidden 96-bit secret from linear equations by combining dual moduli via the Chinese Remainder Theorem and running a 2D lattice reduction.

The challenge leaked equations of the form `y = a*s + e mod q`, where the exact same tiny error `e` was reused across two coprime moduli. By lifting this into a unified CRT equation, I constructed a simple 2-dimensional lattice and extracted the secret using Babai's Nearest Plane algorithm.

CRT combined with LLL

phase / exploitation

The core of the challenge is solving y1 = a1*s + e mod q1 and y2 = a2*s + e mod q2 where `s` is 96 bits and `e` is 176 bits.

Because `e` is identical in both equations, I combined the multipliers and targets using the Chinese Remainder Theorem (CRT) across the moduli `q1` and `q2` to produce a single equation over `Q = q1 * q2`.

The combined equation `Y = A*s + e mod Q` can be rewritten as `A*s - k*Q = Y - e` for some integer `k`. This perfectly describes a lattice target vector!

I formulated the 2-dimensional basis `<(Q, 0), (A, w)>` where `w = 2^(176 - 96)` acts as a scaling factor to balance the bit lengths of the unknown variables. The target vector was set to `(Y, 0)`.

I applied the LLL algorithm to reduce the lattice, followed by Babai's Nearest Plane algorithm to find the closest vector. The resulting point perfectly revealed the 96-bit secret `s`, which I hashed to decrypt the SHAKE256 cipherstream and recover the flag.

import json
import hashlib
import operator

def xor_stream(key, data):
    stream = hashlib.shake_256(key).digest(len(data))
    return bytes(operator.xor(a, b) for a, b in zip(data, stream))

def solve():
    with open('/home/torch/Downloads/challenge.json', 'r') as f:
        data = json.load(f)
        
    q1 = data['q1']
    q2 = data['q2']
    Q = q1 * q2
    
    samples = data['samples']
    s0 = samples[0]
    
    a1 = s0['a1']
    a2 = s0['a2']
    y1 = s0['y1']
    y2 = s0['y2']
    
    A = crt([a1, a2], [q1, q2])
    Y = crt([y1, y2], [q1, q2])
    
    w = 2**(176 - 96) # e_bits - secret_bits
    
    M = Matrix(ZZ, [
        [Q, 0],
        [A, w]
    ])
    
    target = vector(ZZ, [Y, 0])
    
    M_red = M.LLL()
    
    # Babai's nearest plane
    def babai(M, target):
        M_QQ = M.change_ring(QQ)
        G, _ = M_QQ.gram_schmidt()
        b = target
        for i in reversed(range(M.nrows())):
            c = round(b.dot_product(G[i]) / G[i].dot_product(G[i]))
            b = b - c * M[i]
        return target - b
        
    closest = babai(M_red, target)
    print(f"Closest point: {closest}")
    
    s = closest[1] / w
    print(f"Secret: {s}")
    
    key = hashlib.sha256(str(int(s)).encode()).digest()
    flag_ciphertext = bytes.fromhex(data['flag_ciphertext'])
    flag = xor_stream(key, flag_ciphertext)
    print(f"Flag: {flag}")

solve()
