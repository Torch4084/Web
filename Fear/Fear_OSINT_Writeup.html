Exhibit A — the brief
"The site exists. It just doesn't live on the internet you already know. Its address is posted somewhere familiar. Dig around and find out."
  • clue 1"Doesn't live on the internet you already know" — the target isn't on the clearnet. It's reachable through Tor.
  • clue 2"Its address is posted somewhere familiar" — don't hunt for the hidden service directly. Find a familiar-looking hub first and let it point the way.
The trace
clueReading the brief

Two hops are implied before ever touching a browser: reach the dark web, then find whichever "familiar" platform is hosting the real address. That reframes the challenge as a chain, not a single lookup.

relayFinding the familiar hub

"Familiar" on the dark web usually means a clearnet analogue rebuilt on Tor. Thinking in terms of Twitter/X- or Reddit-style platforms pointed straight to Dread — a Reddit-style darknet forum. Opened Tor Browser, pulled the current Dread mirror, and started searching for anything tied to the author, Masquerade. A direct search for that name came up empty.

hintThe extra "a"

An in-challenge hint closed the gap:

"A user with the name Maaasquerade did some unspeakable things in the darknest parts of the web you will find him soon!! He posted a message regarding the flag."

Not a typo — Maaasquerade is the literal handle to search for.

nodeLocating the profile

Searching Dread for the exact handle surfaced the account:

https://dreadytofatroptsdj6io7l3xptbet6onoyno2yv7jicoxknyazubrad.onion/u/Maaasquerade
payloadAn address hidden in plain text

The account's one post:

"Hello traveler here is it sloppygwgsq5iv6vepvk5egkg4zboldkph2okox4dndngx2wwp3bdjid. It is a fun game of choice (Just a message only the smartest will crack it... Are you up for the challenge???)."

Most of that sentence is filler wrapped around one 56-character run of lowercase letters and digits — exactly the shape of a v3 onion address minus the suffix. That's the "familiar somewhere" the description pointed to: the real target's address, buried in a forum post.

sloppygwgsq5iv6vepvk5egkg4zboldkph2okox4dndngx2wwp3bdjid.onion
exitReversed flag

Loading that address in Tor Browser led to the actual challenge page. The flag was sitting right there — written backwards, one last "are you up for the challenge" gate. Reversing the string recovered the real flag in OMNICTF{...} format.

Note
The Maaasquerade account kept getting banned by Dread's moderators, so the author had to redeploy the final page and rotate the flag more than once. By the time this write-up was put together, the flag captured during the first-blood solve no longer matched the live challenge, so the exact value isn't reproduced here — the trace above is the part that held constant across every reset.
