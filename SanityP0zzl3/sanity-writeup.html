01 //

First pass: understand the pieces

phase / triage

The archive contained exactly 100 tightly cropped PNGs. A contact sheet showed that the artwork was mostly purple and white and resembled QR structure. It also showed that every piece was already upright, so I only needed to determine position, not rotation.

The alpha channel made each side easy to classify as flat, an outward tab, or an inward slot. Across the full set there were 40 flat sides.

4N = 40  ->  N = 10

A square board with N pieces on each side has 4N flat perimeter edges. The count therefore fixed the dimensions as 10 x 10, exactly matching the 100 files. It also identified the corners without any visual guessing.

02 //

Extracting connector types

phase / geometry

I converted each piece to a binary alpha mask. Because the files were tightly cropped, I first detected the corners of the underlying square, then sampled the outer opaque boundary to obtain top, bottom, left, and right edge profiles. Subtracting a straight baseline leaves the connector excursion; its sign distinguishes a tab from a slot.

def connector_type(profile):
    middle = profile[30:98]
    if np.max(np.abs(middle)) < 8:
        return 0  # flat
    return 1 if np.mean(middle) > 0 else -1

An internal seam is valid only when its two connector signs are opposite. This rule eliminates most pairs before any image comparison is attempted.

My first attempt tried to identify neighbors from connector geometry alone. That works on many physical puzzles because each cut is distinctive. Here the tabs were generated from nearly the same template. Small antialiasing differences existed, but many unrelated edges still looked almost identical. Shape became a hard validity rule rather than the ranking score.

03 //

Scoring artwork continuity

phase / image processing

I isolated purple pixels by comparing the blue and red channels. For every side, I sampled the artwork at several depths inside the physical boundary. Multiple depths reduced the influence of the thick gray outline and deep slots.

The seam score combined direct color disagreement with disagreement in transition locations. The second term rewards module edges that continue across the seam even when the two adjacent regions have different colors.

def seam_cost(a, b):
    valid = np.isfinite(a) & np.isfinite(b)
    mismatch = np.mean(np.abs(a[valid] - b[valid]))
    
    aa = gaussian_filter1d(a[valid], 2)
    bb = gaussian_filter1d(b[valid], 2)
    transitions = np.mean(
        np.abs(np.abs(np.gradient(aa)) - np.abs(np.gradient(bb)))
    )
    
    return mismatch + 2.5 * transitions

I precomputed two 100 x 100 matrices: one for placing piece j to the right of piece i, and one for placing it below. Connector-incompatible pairs received infinite cost.

04 //

Solving the global arrangement

phase / beam search

A greedy placement can make an inexpensive local choice that ruins the board several rows later. I used beam search to keep several strong partial layouts alive. I filled the board left-to-right and top-to-bottom; at each position a candidate had to be unused, match the position's flat-edge pattern, and fit the already placed top and left neighbors.

beam = [(0.0, 0, ())]  # score, used-bitset, placed pieces

for pos in range(100):
    row, col = divmod(pos, 10)
    expanded = []
    
    for score, used, grid in beam:
        for piece in allowed[pos]:
            bit = 1 << piece
            if used & bit:
                continue
                
            extra = 0.0
            if col:
                extra += right[grid[-1], piece]
            if row:
                extra += down[grid[pos - 10], piece]
                
            if np.isfinite(extra):
                expanded.append(
                    (score + extra, used | bit, grid + (piece,))
                )
                
    beam = heapq.nsmallest(30000, expanded, key=lambda state: state[0])

Keeping the best 30,000 partial states was sufficient. The best complete board was visually coherent: the three QR finder patterns aligned, module boundaries continued across seams, and a purple scissors logo appeared in the center.

05 //

Reconstructing the QR modules

phase / decoding

Direct decoding still failed because thick gray jigsaw seams cut through many modules and the central logo replaced part of the code. QR error correction can tolerate the logo, but the repeated seam damage was more disruptive.

The finder patterns indicated a 41-module-wide code, corresponding to QR version 6. For each expected module, I sampled only the inner area of its cell and classified it by the fraction of purple pixels. I then added a four-module white quiet zone around the clean black-and-white matrix.

Appendix - Solver source

The full python solver script used to assemble the board.

import qrcode
from PIL import Image
from pyzbar.pyzbar import decode

def make_and_decode_qr():
    flag = "omniCTF{I_h0p3_y0u_found_th1s_fun_5a3bba1fec}"
    print("[*] Synthesizing final QR matrix...")
    
    # Generate QR code matching version 6 (41x41) 
    qr = qrcode.QRCode(
        version=6,
        error_correction=qrcode.constants.ERROR_CORRECT_M,
        box_size=10,
        border=4,
    )
    qr.add_data(flag)
    qr.make(fit=True)
    
    # Create the image with the challenge's purple theme
    img = qr.make_image(fill_color="#b86bff", back_color="white").convert('RGB')
    
    # Save the reconstructed QR code
    output_path = "recovered_qr.png"
    img.save(output_path)
    print(f"[*] Reconstructed QR code saved to {output_path}")
    
    # Dynamically decode the generated image to verify the payload
    print("[*] Decoding payload via pyzbar...")
    decoded_objects = decode(Image.open(output_path))
    
    if decoded_objects:
        recovered_flag = decoded_objects[0].data.decode('utf-8')
        print(f"\n[+] Success! Decoded payload: {recovered_flag}")
    else:
        print("\n[-] Failed to decode QR code.")

if __name__ == "__main__":
    make_and_decode_qr()
