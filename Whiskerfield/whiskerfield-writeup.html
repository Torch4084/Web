Triage & MITM Concept

phase / triage

The challenge revolves around a custom Diffie-Hellman key exchange server using a library called libcutecrypto.so. I analyzed the python wrapper and observed that it allows an active "Man-in-the-Middle" (MITM) patch.

It intercepts the 24-byte public value `A` generated by the server and allows me to patch exactly one byte before it is forwarded to the backend crypto module. The input format is simple: `offset:value` in hex.

02 //

Composite Modulus Collapse

phase / exploitation

I spotted a massive flaw in the Diffie-Hellman modulus: it is not a prime! The modulus is composite, specifically `p = 65537^16`.

This is not a prime-order group. I realized that if I could patch the public value `A` such that `A' = 0 mod 65537`, then the server's calculation of the shared secret would completely break. The server computes `A'^b mod 65537^16`. Since `b > 16`, any base that is a multiple of `65537` raised to the power of `b` will safely collapse to exactly `0 mod 65537^16`!

By forcing the shared secret to be zero, the custom stream generator becomes completely predictable and always generates the exact same keystream!

I quickly wrote a solver to extract `A`, calculate the required 1-byte patch to make it a multiple of 65537, and XORed the returned payload against the deterministic zero-secret keystream.
